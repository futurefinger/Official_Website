# Security Policy — Future Finger Technologies

## Reporting Security Vulnerabilities
Future Finger Technologies treats software security as a sovereign operational imperative. If you discover a security vulnerability across our website, products, or infrastructure, please disclose it responsibly.

- **Security Desk:** `futurefingerindia@gmail.com`
- **Response Window:** Preliminary acknowledgement within 24 hours; technical remediation within 72 hours.
- **Scope:** Website source code, API gateways, XShield™ endpoint binaries, and server infrastructure.

## Security Practices
- **No Secret Storage:** No private API credentials, server tokens, or database connection strings are committed to public source control.
- **Binary Verification:** All production executables are Authenticode cryptographically signed and SHA-256 verified.
- **Section 65B Compliance:** Evidentiary telemetry archives comply with Section 65B of the Indian Evidence Act / Information Technology Act 2000.
