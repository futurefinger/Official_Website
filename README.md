## 🚀 Local Development Setup

### Prerequisites
- Node.js (v18+ or v20+ recommended)
- npm (v9+)

### Installation & Run
```bash
# Clone repository
git clone https://github.com/futurefinger/Official_Website.git
cd Official_Website

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build & Local Preview
```bash
# Compile TypeScript & bundle distribution
npm run build

# Preview production build locally
npm run preview
```
